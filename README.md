\# AgentFlow AI — Frontend

Angular frontend for **AgentFlow AI**, a portfolio project for learning and building multi-agent AI task automation. This repository contains the user interface; the Python/FastAPI backend lives in a separate repository.

> **Project status:** Learning project through Phase 2.2. Features below reflect the implementation walkthrough; verify them against the current code before marking them complete.

## Features

- **AI Task Planner:** Submit a goal and display a structured plan generated by an LLM.
- **Task history:** View previously generated plans stored by the backend.
- **Usage details:** Display model name, input/output token counts, and request latency.
- **Research Agent UI:** Request web-assisted research and inspect source links.
- **Tool Agent UI:** Send requests to a tool-using agent and inspect tool execution traces.
- **Request states:** Loading, error, and result displays.

## Tech stack

- Angular (standalone components)
- TypeScript
- Angular Signals and RxJS
- Angular HttpClient

## Getting started

### Prerequisites

- Node.js and npm compatible with the Angular version in `package.json`
- Angular CLI (or use the local CLI via `npx`)
- Running AgentFlow AI FastAPI backend at `http://localhost:8000`

### Install and run

```bash
npm install
npm start
```

If the project does not define an `npm start` script, use:

```bash
npx ng serve
```

Open `http://localhost:4200`.

### Backend configuration

The walkthrough uses `http://localhost:8000/api/v1` as the API base URL. For deployment, move this URL into environment-specific configuration rather than hardcoding it in services.

The backend must allow the frontend origin in its CORS configuration. **Never put an OpenAI API key in the Angular app.**

## Routes

| Route | Feature |
| --- | --- |
| `/` | AI Task Planner and task history |
| `/research` | Research Agent |
| `/agent` | Custom Tool Agent |

## Backend API integration

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/api/v1/planner/generate` | Generate a plan without saving |
| `POST` | `/api/v1/tasks` | Generate and persist a plan |
| `GET` | `/api/v1/tasks` | List recent plans |
| `GET` | `/api/v1/tasks/{id}` | Get a saved plan |
| `POST` | `/api/v1/research` | Research a topic with web search |
| `POST` | `/api/v1/agent/run` | Run a tool-using agent |
